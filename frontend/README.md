# GreenQuest Frontend

React + TypeScript + Vite + Tailwind CSS frontend for GreenQuest.

## Quick Start

```bash
npm install
npm run dev
```

Runs on `http://localhost:5173` and proxies `/api` requests to the FastAPI backend at `http://127.0.0.1:8000`.

## Production Build

```bash
npm run build
```

See the root [README.md](../README.md) for full project documentation and Hacktoberfest details.
